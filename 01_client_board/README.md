# 01_client_board — the client's STIM board, modelled and tested

| Folder | What |
|---|---|
| `model/` | LTspice model of the client's STIM board (`client-board-model.asc`), its model library, symbols, vendor models, the channel subcircuit and electrode load cases. Designators match STIM.SchDoc. Nothing here changes unless the board does |
| `tests/` | Acceptance tests A1–A7, one folder each, regenerated by `tests/make_tests.py`. Start at `tests/README.md` |
| `deck/` | Deck 2 (`02_current-pump-characterization.pptx`, the one shown to the client), its step/figure index, the stage calculator |
| `acceptance-tests.md` | The sim ↔ bench table to fill; deck 2's must-fix list |
